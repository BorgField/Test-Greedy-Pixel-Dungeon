# Greedy Pixel Dungeon

一个基于 [Shattered Pixel Dungeon](https://github.com/00-Evan/shattered-pixel-dungeon) 的自定义修改版本。

## 📖 项目简介

Greedy Pixel Dungeon 是一个专注于**扩展游戏机制**和**增强玩家体验**的地牢探索游戏修改版。在保持原版核心玩法的基础上,添加了新的系统、功能和优化。

## ✨ 主要特性

### 🎮 核心系统
- **战斗状态追踪系统**: 智能检测战斗状态,脱离战斗后触发特殊效果
- **事件驱动架构**: 基于发布-订阅模式的事件系统,支持模块化扩展
- **多平台支持**: Android、Desktop (Windows/Linux/Mac)、iOS

### 🔧 开发特性
- **测试模式 (TestMode)**: 开发者工具,方便调试和测试游戏内容
- **详细的数据查看器**: 实时查看怪物属性、物品信息等
- **自定义挑战选项**: 通过挑战窗口启用/禁用扩展功能

### 🎯 游戏扩展
- 新增物品、怪物和游戏机制
- 优化的用户界面和交互体验
- 保持与原版 ShatteredPD 的兼容性
